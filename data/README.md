# Dataset

Download **NPHA-doctor-visits.csv** from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/936/national+poll+on+healthy+aging+npha) and save it in this folder as:

`data/NPHA-doctor-visits.csv`

The project deliberately does not bundle third-party data. UCI lists the dataset's license as **CC BY 4.0**; retain its source attribution if you redistribute it.
